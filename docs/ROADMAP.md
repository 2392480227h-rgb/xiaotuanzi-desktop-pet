### 已完成的第一版基础

- [x] SVG 角色结构

- [x] 身体与装饰元素
- [x] 基础待机动画
- [x] 点击反馈
- [x] 鼠标悬停反馈
- [x] 键盘互动
- [x] 三种基础互动入口
- [x] 响应式布局
- [x] 离线运行

### 下一轮重点

- [ ] 进一步打磨角色比例、线条和表情呈现
- [ ] 增加更自然的待机细节
- [ ] 建立可扩展的情绪状态结构
- [ ] 让互动反馈与角色状态真正关联
- [ ] 完成 Windows 浏览器人工验收

验收标准：打开页面后，小团子有明确角色形象、稳定视觉识别和基础生命感，并且用户能直观看出后续系统如何继续扩展。

# Phase 1：小团子本人验收表

## 目标

这一阶段不追求“功能很多”，而追求把小团子作为一个独立角色做好：看得清、认得出、点得动、动画稳定、代码容易继续扩展。

## 当前版本应满足

- [x] 页面可直接打开运行
- [x] 使用原生 HTML / CSS / JavaScript / SVG
- [x] 无第三方依赖
- [x] 小团子有独立 SVG 结构
- [x] 标准脸型严格保留：`૮₍ ˃ ⤙ ˂ ₎ა`
- [x] 有基础待机呼吸动画
- [x] 鼠标悬停有反馈
- [x] 键盘 Enter / Space 可互动
- [x] 点击后有动态反馈
- [x] 有三种第一阶段互动入口
- [x] 移动端有响应式布局
- [x] 支持减少动画偏好
- [x] 离线打开不依赖网络资源

## 明天人工验收

1. 双击 `index.html` 是否能正常显示。
2. 小团子在 Windows 浏览器上的字体、脸型和比例是否符合预期。
3. 点击、悬停、键盘操作是否自然。
4. 页面在窗口缩放后是否仍然舒服。
5. 视觉上哪些地方需要继续调整。

## 不在本阶段提前做的东西

- 复杂养成数值
- 账号系统
- 云同步
- 第三方框架
- 自动更新
- 真正的桌面透明窗口

这些会等角色视觉和基础交互稳定后再进入对应阶段。

# 工具链

## GitHub

用途：

- 项目代码托管
- 版本管理
- Issue / PR
- 代码历史
- AI 协作

当前仓库：

`2392480227h-rgb/xiaotuanzi-desktop-pet`

`main`

## VS Code

用途：

- 阅读代码
- 修改代码
- 调试
- Git 操作
- 学习开发环境

建议安装：

- HTML CSS Support
- JavaScript / TypeScript 相关基础支持
- GitHub Pull Requests and Issues
- Live Server（只有需要时再使用）

## Git

用途：

- 保存阶段性成果
- 回滚错误改动
- 查看差异
- 建立可追踪的开发历史

## Browser DevTools

主要使用：

- Elements
- Console
- Sources
- Network
- Application
- Performance

小团子项目会用 DevTools 观察 DOM、CSS、事件、错误和运行性能。

## SVG

SVG 是第一阶段角色绘制的核心技术。

优先建立：

- 身体
- 脸
- 眼睛
- 嘴
- 装饰
- 状态动画

之后再决定是否需要 Canvas 或其他渲染方案。

## AI 协作

AI 负责：

- 分析需求
- 解释知识
- 设计方案
- 编写和修改代码
- 调试
- 检查质量
- 维护文档

开发过程中仍然需要理解关键代码和架构。

## 明日工作流

1. 先确认当前仓库状态
2. 运行最小原型
3. 设计小团子 SVG
4. 实现角色结构
5. 加入第一组动画
6. 浏览器检查
7. 修复问题
8. 提交 Git
9. 记录下一阶段任务

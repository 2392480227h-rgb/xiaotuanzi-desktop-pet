# 小团子养成屋

一个从零开始打造的桌面宠物项目。

## 项目目标

把小团子从一个固定的视觉角色，逐步做成一个真正可以陪伴、互动、成长、运行在桌面上的数字宠物。

标准脸型必须严格保持：

`૮₍ ˃ ⤙ ˂ ₎ა`

## 技术路线

第一阶段坚持使用透明、容易理解的原生技术：

- HTML
- CSS
- JavaScript
- SVG
- Browser DevTools
- Git / GitHub
- VS Code

暂不引入 React / Vue 等框架。等原生架构真正理解并出现明确需求后，再考虑升级技术栈。

## 开发原则

1. 先理解，再实现。
2. 每一步都保持可运行。
3. 小团子的角色设定和视觉标准不能被随意改动。
4. 功能、代码结构、交互和视觉都追求完整作品感。
5. 不为了“能跑”牺牲可维护性。
6. 每个阶段都留下清晰的 Git 记录。
7. 学习过程中优先让项目成为练习场，而不是单纯让 AI 代写。

## 当前阶段

项目初始化完成后，先做“小团子本人”：

1. 角色结构
2. SVG 视觉
3. 基础动画
4. 鼠标互动
5. 状态系统
6. 养成系统
7. 数据持久化
8. 桌面宠物化
9. 最终打磨

## 开发入口

直接打开 `index.html` 即可运行当前原型。

后续如果需要本地开发服务器，再根据实际需求引入最小化工具，不提前堆依赖。
